📊 Sheet 03 字段定义

  • 扫描时间:本表生成时间
  • 产品名:snowears.com 商品标题
  • Handle:URL slug
  • 当前价:最低可用变体价
  • 原价:compare_at_price,无则空
  • 折扣率:无则"无折扣",有则"X% off"
  • Sale状态:是否在售折扣
  • Collection1/2/3:所属 collection,多值
  • 产品URL:https://snowears.com/products/<handle>
  • 库存状态:全部有货留空,缺货颜色写"XX-无库存"
  • 变体数:variants 数量(颜色 × 尺码组合)
  • 评分:0-5 星,无评分写 0
  • 评论数:累计评论数,无评论写 0
  • 本周新增评论数:上周六至本周五新增评论,首次快照写 0
  • 是否首页产品:本次扫描在首页主推则标"是",否则留空
  • 历史首页时间:过去曾在首页的时间段,格式"2026/03/02-2026/05/02"
