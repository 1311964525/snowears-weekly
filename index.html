📊 Sheet 03 字段

  • 扫描时间:本表生成时间
  • 产品名:snowears.com 商品标题
  • Handle:URL slug
  • 当前价:最低可用变体价
  • 原价:compare_at_price,无则空
  • 折扣率:无则"无折扣",有则"X% off"
  • Sale状态:是否在售折扣
  • Collection(产品分类):对应 Shopify product_type,单值(无空格)独立可筛
  • 产品URL:完整商品页 URL
  • 库存状态:全部有货留空,缺货颜色写"XX-无库存"
  • 变体数:variants 数量(颜色 × 尺码组合)
  • 是否首页产品:本次扫描在首页则"是"
  • 历史首页时间:过去曾在首页的时间段

📈 周变动日志字段

  • 周状态:新增 / 已存在 / 已下架
  • 首页状态:首页新进 / 首页持续 / 首页退出 / 不在首页
  • 每次 snapshot 留档到 data/history/

🎟️ Sheet 05 字段

记录 active 状态的折扣码和无码促销活动,共 4 项(LABOR20 + 3 项无码)。

📝 Sheet 06 字段

博客追踪,共 10 篇。字段:发布时间 / 标题 / 分类 / 作者 / 标签 / 关联产品数 / 提到的产品 / 本周产品变化(对比上次快照)
